## 摘要
检索增强生成（RAG）通过将大型语言模型（LLM）基于文本语料库等外部知识来改进问答。然而，其推理过程在很大程度上仍然是不透明的：中间推理步骤难以验证，也无法可靠地归因于特定证据。此外，缺失的用户特定上下文很少被系统性地检测到，常常导致不完整或不正确的输出。我们提出了NeSy-RAG，一种模块化的神经符号RAG框架，它从检索到的文本块中综合可归属的Prolog模块。对于每个块，系统生成语义上有意义的谓词，这些谓词编码布尔声明，可能依赖于用户事实。利用联合自然语言-代码嵌入，谓词被检索并组合成Prolog查询。为了解决不完整的用户上下文，我们引入了一种符号知识差距检测机制，该机制识别缺失的用户事实，这些事实的真值影响查询结果，并自动触发后续交互。执行生成的Prolog查询可产生确定性答案，并提供透明的执行轨迹，将每个推理步骤与其来源链接起来。在ShARC基准上，无需领域特定训练，NeSy-RAG达到了61.1%的准确率，优于相同模型RAG基线的42.8%准确率。

## Abstract
Retrieval-augmented generation (RAG) improves question answering by grounding large language models (LLMs) in external knowledge such as text corpora. However, its reasoning process remains largely opaque: intermediate reasoning steps are difficult to verify and cannot be reliably attributed to specific evidence. Moreover, missing user-specific context is rarely detected systematically, often leading to incomplete or incorrect output.   We propose NeSy-RAG, a modular neuro-symbolic RAG framework that synthesizes attributable Prolog modules from retrieved text chunks. For each chunk, the system generates semantically meaningful predicates that encode Boolean claims, which may depend on user facts. Using joint natural language-code embeddings, predicates are retrieved and composed into Prolog queries. To address incomplete user context, we introduce a symbolic knowledge-gap detection mechanism that identifies missing user facts whose truth values affect the query outcome and automatically triggers follow-up interactions.   Executing the resulting Prolog queries yields deterministic answers together with transparent execution traces that link each reasoning step to its originating source. On the ShARC benchmark, without domain-specific training, NeSy-RAG achieves 61.1% accuracy, outperforming a same-model RAG baseline that achieves 42.8% accuracy.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：检索增强生成（RAG）通过将大语言模型（LLM）的生成过程锚定在外部知识（如文本语料库）上来提升问答的准确性，已成为领域特定问答的主流方案。
- **核心问题**：尽管 RAG 能提升事实准确性，其推理过程仍存在三个主要缺陷：
  - **推理不透明**：中间推理步骤难以验证，标准的思维链（CoT）不能提供令人信服的解释。
  - **归因不充分**：生成的答案无法可靠地追溯到具体的源文本，在医疗、法律等高风险场景中阻碍信任与安全部署。
  - **用户特定上下文缺失难以检测**：当回答需要用户个性化信息（如身份、资格等）而该信息缺失时，现有系统很少能系统性地感知并主动追问，导致输出不完整或错误。
- **整体含义**：作者提出将神经符号方法引入 RAG 流程，利用 Prolog 的确定性推理和可解释性来弥补纯 LLM 推理链的不足，从而构建更可信、可验证的问答系统。

## 2. 论文提出的方法论：核心思想、关键技术细节与算法流程

- **总体框架**：NeSy-RAG 设计为现有 RAG 系统的即插即用扩展，输入为检索到的文本块和用户问题，输出为带有可解释执行轨迹的确定性答案。
- **核心思想**：将检索到的文本片段转化为模块化的、可归属的 Prolog 知识库，通过符号推理来计算答案，使得每一步推理都可追溯到其来源文本。

- **关键技术细节——四大核心组件**：

  1. **可归属的 Prolog 合成（Attributable Prolog Synthesis）**
     - 对每个检索到的文本块，用 LLM 单独合成一个 Prolog 模块（包含规则和事实）。
     - 模块化的优势：简化合成复杂度（每个块信息量有限）；每个事实/规则可唯一映射到其来源文本块，支持细粒度的可解释性和验证溯源。

  2. **0-arity 谓词抽象（0-Arity Predicate Abstraction）**
     - 在模块合成时，LLM 额外生成无参数的规则（0-arity），将模块功能封装为自包含的布尔声明（如 `could_claim_married_couples_allowance`）。
     - 好处：使查询构建无需加载知识库细节；将查询生成任务转化为“谓词选择与组合”；缩小搜索空间、减少 LLM 幻觉。

  3. **符号化知识缺口检测（Symbolic Knowledge-Gap Detection）**
     - 将事实区分为**普遍事实**和**动态事实**：动态事实含至少一个无法在合成时确定、须在推理时实例化的参数（如“用户是否达到法定年龄”）。
     - 对动态事实生成交互方法：当 Prolog 执行到该事实时自动触发，向用户提问以获取/确认其布尔值；若用户无法回答，则分别在该布尔值两种赋值下求值，判断结果是否受影响，以此系统性地决定输出 **more**（无法确定）。

  4. **分层检索与查询问答（Hierarchical Retrieval & QA）**
     - **第一层**：基于向量嵌入检索相关文本块。
     - **第二层**：抽取各模块中的 0-arity 谓词，用联合 NL–PL 嵌入模型（`jina-code-embeddings-1.5b`）按与用户问句的余弦相似度排序，取 top-k 交给 LLM 组成 Prolog 查询。
     - 执行查询后获得确定性结果和**执行跟踪信息**——跟踪信息包含事实/规则来源模块及文本块信息，支持进一步的查验。

- **算法流程**（文字说明）：
  1. 对检索到的每个文本块，LLM 合成一个含动态事实、规则和 0-arity 规则的 Prolog 模块；
  2. 将用户的自然语言问句嵌入并与候选 0-arity 谓词进行相似度排序，取 top-k；
  3. LLM 只用这 top-k 的 0-arity 谓词构造 Prolog 查询；
  4. 执行查询；遇到动态事实时自动向用户（或模拟用户）提问；
  5. 若缺失信息影响查询结果且用户无法回答，输出 **more**；否则输出确定性的 **yes/no** 并附带完整的执行追踪轨迹。

- NeSy-RAG 在 ShARC 上达到 **61.1%** 的准确率（k = 10），显著优于同模型 RAG 基线的 **42.8%**（gpt-oss:20b），也优于 gpt-5-mini RAG 基线（53.7%），证明了符号推理对检索问答的有效增强。
- NeSy-RAG 的平均推理耗时（**约 7.4 秒/实例**）低于 LLM RAG 基线的（11.4 秒），主要归因于模块可复用、上下文窗口小、追问由算法触发而非额外 LLM 调用。

## 7. 优点：方法与实验设计的亮点

- **模块化可归属的符号知识表示**：每个事实和规则可追溯到具体源文本块，实现了真正的细粒度来源归因，为可验证推理提供了坚实基础。
- **0-arity 谓词抽象**创新性强：将查询生成从“开放性知识库探索”转变为“受限谓词组合”，有效缓解了 LLM 查询生成的不可扩展性和幻觉问题。
- **层级检索框架**（先块级检索、后谓词级检索）兼顾了大语料库与大型知识库的可扩展性。
- **符号化的知识缺口检测**：能够系统性地识别缺失用户信息并与其交互，克服了纯 LLM 难以主动寻求缺失信息的局限。
- **确定性推理 + 透明执行轨迹**：输出可复现、可验证，每条推理路径都有明确的逻辑链与来源标注。
- **无需领域训练的即插即用设计**：可直接集成到现有 RAG 流水线中，工程实用价值高。
- **效率层面有优势**：模块复用及小上下文窗口带来更低的推理时间，同时也暗示了明显的 token 成本节约潜力。
- **实验条件相对公平**：NeSy-RAG 与 RAG 基线采用相同的设置（相同模型、需要主动获取用户信息），并与上界基线和有训练方法对比，定位清晰。

## 8. 不足与局限

- **动态谓词过度生成**：导致大量应为 `yes/no` 的实例被保守地判为 `more`（31% 的 yes 被误判为 more），是当前准确率缺口的主要来源。
- **实验覆盖有限**：仅在 ShARC 单一基准上评测，缺少跨数据集与跨领域验证；多跳/多文档/真实检索场景未涉及（本文实验假设单相关片段 + 随机干扰片段）。
- **未做消融分析**：未系统评估各组件（如知识缺口检测、0-arity 谓词提炼、NL2C 检索等）的独立贡献。
- **LLM 合成 Prolog 的可靠性**：实验中有约 2.2% 的样本因 Prolog 语法错误而执行失败，说明 LLM 代码生成的健壮性仍有改进空间。
- **动态事实类型受限**：只支持带单个布尔参数的用户事实，对更丰富的数据类型（数值、枚举、复合结构）尚不支持，限制了方法的广义适用性。
- **对底层检索质量有依赖**：NeSy-RAG 整体性能取决于底层检索机制的质量和领域知识的完善程度，若检索返回缺失相关片段则符号推理也无法弥补。
- **零样本性能与有监督 SOTA 差距明显**：61.1%（NeSy-RAG）相对有训练的 BiAE 的 77.9% 仍有约 17 个百分点的差距，说明无训练方法目前仍难以超越领域专用模型。
