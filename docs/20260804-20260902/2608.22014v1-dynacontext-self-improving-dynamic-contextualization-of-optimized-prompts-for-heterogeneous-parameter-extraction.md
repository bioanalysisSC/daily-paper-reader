## 摘要
自动化提示词与技能优化通常产生一条静态指令，并在下一次优化周期之前跨推理实例复用。然而，当所需上下文、约束和证据随实例不同而变化时，此方法无法适应。例如，从电子元件描述中提取参数就打破了这一假设：电阻、电容、晶体管和连接器需要不同的字段、单位约束和演示，且每个输入提供不同的证据状态。我们提出DynaContext，一个将使用GEPA或SkillOpt学习到的离线优化提取核心与推理时上下文适应及验证门控自改进相结合的框架。DynaContext通过内部、外部或回退证据路径路由每个条目，并从核心、模式、证据、未解析字段和已验证演示中组合出特定于条目的提示词。确定性验证和LLM评判器对每个输出进行门控，不确定案例进入人工复核，且只有人工验证的修正才会进入演示记忆。在单类别基准上，平均准确率从基础提示词的86.6%提升至独立SkillOpt的96.9%，以及最佳DynaContext配置的98.6%。在850条异构黄金参数事实上，平均字段级F1从无优化、无演示对照的51.8%提升至仅使用动态演示的59.2%、仅使用优化核心的66.9%，以及两者结合时的71.0%。在固定模型不变的情况下，完整配置平均比部署的静态提示词流水线高出17.3个F1点。

## Abstract
Automated prompt and skill optimization typically produces a single static instruction that is reused across inference instances until the next optimization cycle. However, this approach cannot adapt when the required context, constraints, and evidence vary from one instance to another. For instance, parameter extraction from electronic component descriptions breaks this assumption: resistors, capacitors, transistors, and connectors require different fields, unit constraints, and demonstrations, and each input provides a different evidence state. We introduce DynaContext, a framework that combines an offline-optimized extraction core, learned with GEPA or SkillOpt, with inference-time contextual adaptation and validation-gated self-improvement. DynaContext routes each item through internal, external, or fallback evidence paths and composes an item-specific prompt from the core, schema, evidence, unresolved fields, and validated demonstrations. Deterministic validation and an LLM judge gate every output, uncertain cases go to human review, and only human-verified corrections enter the demonstration memory. On a single-category benchmark, average accuracy increases from 86.6% for the base prompt to 96.9% for standalone SkillOpt and 98.6% for the best DynaContext configuration. Across 850 heterogeneous gold parameter facts, average field-level F1 increases from 51.8% for an unoptimized, demonstration-free control to 59.2% with dynamic demonstrations alone, 66.9% with the optimized core alone, and 71.0% with both. Holding the model fixed, the full configuration outperforms the deployed static-prompting pipeline by 17.3 F1 points on average.

## 1. 核心问题与整体含义

- **背景**：自动化提示词优化（如 GEPA、SkillOpt、DSPy 等）通常输出一条固定指令，在下一轮优化前对所有推理实例复用。这假设所有输入具有相同的输出结构、证据状态和格式要求。
- **问题**：电子元件参数提取打破该假设——电阻、电容、MOSFET、连接器等类别具有不同的字段集合、单位约束和语义；同一类别内的每条供应商描述可能对应完全不同的证据状态：有的能匹配内部记录，有的能用外部 API 或规格书验证，有的只能靠描述推断。
- **目标**：构建一个能随实例动态调整上下文、同时保留离线优化收益的框架，并让系统通过“验证门控”的方式自我改进，而不是每次更新都依赖重新优化全部提示。

## 2. 方法论

### 2.1 总体思想

DynaContext 将“离线优化什么”与“推理时组合什么”分离：

- **离线**：用 GEPA 或 SkillOpt 学习一个可复用的“提取核心”（即优化后的指令片段）；
- **推理时**：针对每个输入，根据证据路径动态组合提示（scheme、证据摘要、未解析字段、检索到的已验证演示）；
- **自改进**：只有通过确定性校验、LLM 评判和人工复核的修正才能写入演示记忆。

### 2.2 关键流程

- 输入记录包含描述、MPN、制造商、类别提示、已有证据；输出为结构化记录，包括解析类别、选定 schema、字段值、未解析字段、状态与来源元数据。
- **路由策略**（算法 1）：
  - 内部路由：存在可信内部精确 MPN 匹配时，直接恢复完整记录，不调用 LLM；
  - 外部路由：无内部匹配但外部 API/官方规格书可验证 MPN 时，使用该证据填充，LLM 只补缺失字段；
  - 回退路由：两者都不可用时，从描述推断类别和 schema，做完整的基于描述的抽取。
- **回退抽取**：用 Jaro–Winkler 相似度匹配类别；从已验证演示记忆检索类别匹配样例（向量、BM25 或混合），但演示是上下文提示而非证据来源。
- **提示组合公式**：  
  \( P_t(x_i) = A^{*}_{\hat c_i,t} \;\oplus\; S_{\hat c_i} \;\oplus\; M_i \;\oplus\; \phi(E_i) \;\oplus\; d_i \;\oplus\; R_k(x_i,M_t) \)
  - A*：离线优化提取核心；S：选定 schema；M：未解析字段集；φ(E)：证据摘要；d：原始描述；R_k：检索演示。
- **验证机制**：
  - 确定性校验覆盖预处理、schema 选择和后处理；
  - LLM judge（离线用 GEPA 优化其提示）只做三分类（通过/拒绝/送审），不能增改参数值；
  - 人工复核决定是否接受修正；
  - 只有人工验证的案例进入演示记忆 Mt+1；GEPA 基于接受/修正轨迹再次离线优化。
- 文档强调：内部/外部 MPN 路径不进行相似搜索或演示检索，路由策略是确定性的，从而将推理时适配限制在明确的安全约束内。

- **实验规模**：两个基准、8 个模型、多种路由/核心/检索条件，共约几十组条件组合（单类别有 3 cores×4 retrieval 级别，另有 k=1/3/5/10 扫描；多类别为 2 cores×2 演示开关×8 模型的两因数消融）。

## 6. 主要结论与发现

- 静态优化提示在异构参数提取中显著弱于“离线优化核心＋推理时动态上下文”的架构。
- 动态演示与优化核心的收益是**次加性**的：两者单独分别提升 +7.47 和 +15.14 F1，结合后总增益 +19.22，说明二者提供部分重叠信息（如 schema、格式、null 行为）。
- 一旦类别/schema 固定（单类电容），动态上下文能把平均准确率推到接近天花板（98.6%），剩余差距主要是 schema 解析差距。
- 成本/质量上，小模型+上下文正确组合可超过大模型+静态提示；错误路径分析将失败分类到提取器、证据获取、评判器等组件，为可定向改进提供依据。

## 7. 优点

- **方法亮点**：
  - 将优化提示从“静态复用”转化为“动态实例化”，保持核心稳定同时逐条调整上下文，突破口与既有框架互补；
  - 路由过程有确定性逻辑与安全闸门，LLM 只在允许的路径上运行；
  - 输出的字段级溯源与强制弃权（如无证据则留空）支持工程可审计性；
  - 自改进不是无条件吸收任何输出，而是先经确定性校验、LLM judge 分流、人工复核三级门控；
  - 把 judge 作为门而非标签来源，避免模型自我确认偏差。
- **实验设计优点**：
  - 单类/异构双基准设计能分离“类别解析能力”与“上下文检索能力”；
  - 多模型配对设计控制了模型差异，结果更客观；
  - 用 8 个模型证明增益并非依赖某一模型，成本对比也很清楚。
