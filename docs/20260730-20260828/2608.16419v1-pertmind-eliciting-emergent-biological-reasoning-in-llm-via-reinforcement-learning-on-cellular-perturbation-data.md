## 摘要
大语言模型能够描述机制，然而可扩展的后训练仍然依赖于昂贵的人工整理的生物学推理轨迹。我们展示了细胞扰动图谱可以转而成为强化学习环境，其中测量的基因响应为生物学推理提供可计算的奖励。我们介绍了PertMind，它结合了可信轨迹监督初始化与基因、通路和格式层面的强化信号。仅在正向扰动-响应预测上训练，PertMind在未见过的细胞环境中改进了响应推断，同时保留了通用语言能力。它还无需特定任务的后训练便迁移到反向扰动识别、双扰动推理、表型筛选优先排序和生物过程解释。PertMind进一步生成了生物特征，支持跨尺度下游任务中具有竞争力的基因、细胞和供体表示。这些结果支持一个假设：对实验终点的强化学习能够集中预训练模型已经可访问的可重用生物学策略。更广泛地，扰动衍生的强化学习提供了一条可扩展的途径，将不断扩大的实验图谱转化为通用生物学推理的训练环境。

## Abstract
Large language models can describe mechanisms, yet scalable post-training still depends on costly, manually curated biological reasoning traces. Here we show that cellular perturbation atlases can instead become reinforcement-learning environments, where measured gene responses provide computable rewards for biological reasoning. We introduce PertMind, which combines trusted-trajectory supervised initialization with gene-, pathway-, and format-level reinforcement signals. Trained only on forward perturbation-response prediction, PertMind improved response inference in unseen cellular contexts while retaining general language capabilities. It also transferred without task-specific post-training to reverse perturbation identification, double-perturbation reasoning, phenotypic-screen prioritization, and biological-process interpretation. PertMind further generated biological profiles that supported competitive gene, cell, and donor representations across multiscale downstream tasks. These results support the hypothesis that reinforcement on experimental endpoints can concentrate reusable biological strategies already accessible to pretrained models. More broadly, perturbation-derived reinforcement learning offers a scalable route for transforming expanding experimental atlases into training environments for general-purpose biological reasoning.

### 2. 方法论

**核心思想：**
把"给定 (c, d, g) 预测目标基因响应方向"视为一个多步生物过程（扰动靶向→通路传播→细胞环境调控，最终在靶基因处产生可测的表达变化）的可计算投影；用实验终点的正确性作为强化信号，让模型自行探索并集中能正确收敛到实验终点的推理策略，而不是人工注释每一步中间推理。

**技术流程（三阶段）：**

1. **扰动派生监督语料构建（Section 2.2）**
   - 直接使用 Tahoe-100M 预计算的 DESeq2 风格伪批量差异表达统计量；按全实验条件 (d, dose, plate) 经过质量过滤后，以 "最大 |log2FC| 记录" 规则合并为 (c,d,g) 级记录。
   - 标签规则：
     - `Up`：q ≤ 0.05 且 log2FC ≥ log2(1.5) ≈ 0.585
     - `Down`：q ≤ 0.05 且 log2FC ≤ −0.585
     - `No`：|log2FC| < 0.20 且 q ≥ 0.50 且 baseMean ≥ 10
     - 其余为 `ambiguous`，剔除
   - 每个三元组有置信度权重 w_conf ∈ [0.1, 1]，由（Δ, q, μ）计算，用于 RL 阶段缩放整个三元组的优化步长。
   - **严格防泄漏**：先按细胞系划分，Ctrain ∩ Ctest = ∅；测试细胞系为 C32、HepG2C3A、HOP62、Hs 766T、PANC-1；所有检索池仅限训练划分，当前查询标签/表达统计/通路代理标签均不进入模型侧。

2. **知识增强的 RL 初始化：可信轨迹 SFT（Section 2.3）**
   - 检索模块从 PubChem、DrugBank、UniProt、GO、Reactome、STRING、CORUM 组装生物上下文 K(x)，并从训练集检索结果分层支持案例 S(x) = S_Up ∪ S_Down ∪ S_No（不泄露当前查询标签）。
   - 当前 Qwen3-4B 模型采样 M=8 条候选轨迹，通过五条过滤器（最终标签正确、输出结构合法、不声称访问隐藏表达值、实体关系有上下文支持、推理链完整从靶点到通路到基因结论）方可进入可信轨迹集。
   - 对可信轨迹做一轮 BFT（Balanced Fine-Tuning）加权 SFT：局部低置信 token 降权，含困难区间的轨迹序列级升权，得到 RL 初始策略 πθSFT。

3. **通路监督 GRPO（Section 2.4）**
   - 对每条查询预先（不看任何 (c,d) 特异性表达结果）选最多 3 条包含 g 的 Reactome 通路作为候选，用与结果无关的基因-药物机制证据排序。
   - 奖励 = R_gene + λ_pw·m_pw·R_pw + λ_fmt·R_fmt（λ_pw=0.15、λ_fmt=0.05，满足 λ_pw+λ_fmt < 1，保证辅助奖励永远不能压倒基因标签正确性）。
   - R_gene：最终基因方向判断是否等于实验标签（无解析标签记 0）。
   - R_pw：对确定性的通路子集 P_det 计算模型预测的方向（Up/Down/No）与条件级转录通路代理标签的一致性均值；通路代理由非靶基因成员 P−g 的显著性加权符号效应、符号一致性、活跃成员比例经保守跨条件共识计算，模型不知道哪些通路被打分。
   - R_fmt：所有必需字段齐全、标签在合法词表内、只有一个可解析的最终答案。
   - GRPO 组内标准化优势，置信度 w_conf 作为对象级乘子整体缩放（不改变组内排序）；KL 向冻结的 SFT 参考惩罚（β=0.01），采用采样 token 的 KL 估计，保留 SFT 建立的结构化输出与推理模式。

### 4. 主要结果

**端到端响应预测：**
- PertMind（BFT + 通路监督 GRPO）在 5 个未见细胞系测试集上的平均准确率和宏 F1 显著优于所有基线。
- 与最强零样本 Qwen3-4B 相比，平均准确率提升约 10–15 个百分点；与 SFT-only 相比，GRPO 阶段带来额外 3–6 个百分点的提升，说明强化学习在修正 SFT 固化偏差和适应实验标签分布方面有实际增益。
- Up/Down 分类的优势尤其明显，No 类召回也有改善；模型不再是简单偏向高频类，而是能利用上下文激活通路状态判断无变化。

**跨细胞系泛化：**
- 测试细胞系均为训练中完全未见过的类型，PertMind 仍能保持较高的预测一致性，说明模型并非记忆特定细胞系的标签分布，而是学会了跨细胞系通用的"药物-通路-基因"传播推理模式。
- 尤其对 HepG2C3A（肝来源）和 PANC-1（胰腺）等与训练主流细胞系谱系差异较大的系，仍观察到明显超过基线的增益，证明机制推理的可迁移性。

**难例分析与标签分层表现：**
- 在低置信度（w_conf 低）或效应边界（|log2FC| 轻微超过阈值）的三元组上，PertMind 的准确率下降幅度小于 SFT 基线与零样本基线，说明 RL 在不确定信号上学会了保守倾向，而非激进猜测。
- Down 标签的 F1 在纯基因奖励变体中偏低，加入通路奖励后显著回升，验证了辅助通路监督对响应方向判断（特别是抑制性扰动）的补充作用。

### 5. 消融与组件贡献

**可信轨迹 SFT 的必要性：**
- 纯 GRPO（无 SFT 初始化）训练不稳定，输出格式混乱，最终准确率明显低于有 SFT 的完整流程。可信轨迹过滤本身（筛选 M=8 条中的合格轨迹）比简单行为克隆全部采样轨迹更有效：过滤掉"推理花哨但结论错误"的轨迹后，SFT 初始化更干净，RL 更容易在正确策略上集中。

**通路奖励的作用：**
- 去除 R_pw（仅用基因标签奖励）时，整体准确率下降 2–4 个百分点，且通路中间推理的自然语言描述质量明显退化（模型倾向于快速跳到答案，不再展开多步机制）。
- 通路奖励权重 λ_pw=0.15 是最优选择：太低则失去机制引导，太高（接近 1）会牺牲最终标签准确率——与理论约束 λ_pw+λ_fmt < 1 一致。

**置信度加权的作用：**
- 去掉 w_conf 后，模型在低置信度样本上过度自信，准确率在困难区间下降；加入权重后优化步长与证据强度挂钩，相当于隐式告诉模型"拿不准时少改变策略"，减少了过拟合噪声标签。

**奖励工程细节：**
- R_fmt 虽然权重仅 0.05，但对训练稳定性至关重要：无格式奖励时 GRPO 后期 KL 漂移导致输出结构崩塌，加入后结构化输出保持稳定。
- 使用冻结 SFT 参考的 KL 惩罚（β=0.01）防止 RL 策略偏离初始推理模式过远，避免产生"幻觉通路但正确标签"的不良策略。

### 6. 案例分析

**案例 1：多种药物作用于同一基因**
- 查询多个药物（如不同激酶抑制剂）对同一靶基因的响应判断。模型能区分"直接靶向该基因"与"间接通过上游通路影响"两种情境，在直接靶向时给出高置信 Up/Down，间接时结合通路传播逻辑判断。
- 通路奖励使模型生成的推理链中包含与 Reactome 一致但未出现在检索知识中的中间节点，说明 RL 奖励确实促进了知识的重组而非简单复读。

**案例 2：同一药物在不同细胞系中的不同方向**
- 给定相同药物与基因，但不同细胞系时，PertMind 自动引入细胞类型差异（如 TP53 状态、增殖速率）作为通路调节因子，判断方向翻转。这类行为在零样本与 SFT 基线中几乎不出现，体现了 RL 对数据中细胞依赖性模式的挖掘。

**错误案例分析：**
- 典型错误发生于通路代理标签与真实表达标签冲突时：模型采纳了通路共识方向但最终基因标签错误。这说明辅助奖励虽然能够引导中间推理，但无法完全覆盖复杂上下文交互；论文承认这是未来改进方向（如引入更细粒度的通路状态估计）。

### 7. 结论与局限性

**结论：**
- 论文表明：大规模细胞扰动图谱可以作为无需人工步骤标注的强化学习信号来源；通过"预测终点"+辅助通路监督，能够以可扩展方式为 LLM 注入生物学机制推理能力。
- PertMind 在未知细胞系上持续超越强基线，证明了该范式从"数据规模"和"无人工标注"两个维度都具备可持续扩展性。
- 该工作也验证了奖励工程中的关键原则：辅助奖励权重严格受主任务正确性约束，置信度按证据强度缩放，格式奖励保持结构稳定——这些设计对生物医学 LLM 后训练具有通用价值。

**局限性与未来工作：**
- 通路代理标签仍依赖预先计算的条件级共识，可能掩盖部分细胞类型特异的通路行为；跨条件保守共识的偏置需进一步降低。
- 当前模型推理以自然语言轨迹承载，但并非所有中间步骤都可被奖励解释，存在"奖励黑客"的残留风险。
- 测试集仅覆盖 5 个细胞系，更多谱系（如原代细胞、类器官）的泛化尚未验证。
- 下游下游任务（如药物组合预测、耐药机制解释）的迁移尚未评测，这是自然延伸方向。
- 计算成本方面，M=8 采样和多次 GRPO 迭代在 4B 模型上可负担，但更大模型的扩展效率未测试。
