## 摘要
CASCADE是一种代理框架，通过MCP暴露的预计算ARACNe调控网络预测基因扰动的下游转录效应。先前的工作通过检查预测基因是否为已知癌症基因（成员资格）来验证此类工具；我们则测试预测的变化方向是否与现实一致，使用焦点基因拷贝数扩增作为敲低逆效应的剂量代理，针对真实的TCGA患者肿瘤数据进行验证。对于MYC，CASCADE预测的敲低靶标在三种癌症类型（BRCA: 90.0%, COAD: 72.0%, STAD: 85.7%；均p<0.0013）中与实际扩增与非扩增肿瘤表达高度一致，显著高于置换基线，并通过PAM50亚型对照，在独立队列（METABRIC, 87.2%）中复现。与通过Fisher精确检验的精选MSigDB基因集基线相比，CASCADE的准确性未显示出超越现有公开的MYC或E2F驱动生物学知识，但其基因特异性方向判定明显优于朴素的均匀猜测。扩展到另外十五个基因，验证证明是基因特异性的而非普遍性的：增殖机制调节因子大多可复现，而谱系同一性转录因子和一个细胞周期蛋白D旁系同源物（CCND2）持续失败，我们将此模式作为有保留的事后假设进行讨论。我们另外评估了基于LLM的代理是否能正确地将自然语言请求落地为CASCADE真实的MCP工具调用。在35个查询中，一个有记录可查的本地模型达到71.4%的精确匹配（较大模型为85.7%）；模式和基因别名失败可通过规模或服务端修正解决，但两个模型在模糊查询上都自信地默认使用错误的扰动类型，这是一个针对性的修复无法解决的失败，因为其触发条件从未发生。

## Abstract
CASCADE is an agentic framework that predicts downstream transcriptional effects of gene perturbation from precomputed   ARACNe regulatory networks, exposed via MCP. Prior work validates such tools by checking whether predicted genes are   known cancer genes (membership); we instead test whether the predicted direction of change matches reality, using   focal-gene copy-number amplification as a dosage-based proxy for the inverse of knockdown against real TCGA patient   tumor data.   For MYC, CASCADE's predicted knockdown targets show strong concordance with real amplified-vs-non-amplified tumor   expression across three cancer types (BRCA: 90.0%, COAD: 72.0%, STAD: 85.7%; all p<0.0013), well above permutation   baselines, surviving a PAM50 subtype control and replicating in an independent cohort (METABRIC, 87.2%). Compared   against curated MSigDB gene-set baselines via Fisher's exact test, CASCADE's accuracy is not shown to exceed existing   public knowledge of MYC- or E2F-driven biology, though its gene-specific direction-calling clearly outperforms a naive   uniform guess.   Extending to fifteen additional genes, validation proves gene-specific rather than universal: proliferation-machinery   regulators mostly replicate, while lineage-identity transcription factors and one cyclin-D paralog (CCND2)   consistently fail, a pattern we discuss as a hedged, post-hoc hypothesis.   We separately benchmark whether an LLM-based agent correctly grounds natural-language requests into CASCADE's real MCP   tool calls. Across 35 queries, a documented local model reaches 71.4% exact match (85.7% for a larger model); schema   and gene-alias failures are resolved by scale or server-side correction, but both models confidently default to the   wrong perturbation type on ambiguous queries, a failure a targeted fix could not resolve because its trigger condition   never occurs.

## 1. 核心问题与研究动机

- **背景问题**：预测基因扰动（如敲低、过表达）的下游转录效应是癌症系统生物学的核心任务，现有工具（如基于预计算调控网络的传播算法）能够低成本地生成预测，但验证方式存在根本缺陷。
- **既有验证的局限**：此前验证方法（如对 RegNetAgents 的验证）只检查预测的候选基因是否命中已知癌症基因注释库（"成员资格验证"），**从不检验预测的具体方向性声明**（"该基因上调还是下调"）是否符合真实疾病中会发生的情况。当工具通过 MCP 作为可调用函数暴露给 LLM 代理时，这一验证鸿沟会直接传递给下游用户。
- **本文的解决方案**：CASCADE 提出直接使用**真实患者肿瘤数据**（TCGA 和 METABRIC）来验证方向性预测——将焦点基因的拷贝数扩增视为敲低的逆效应（剂量代理），检验 CASCADE 预测的靶基因表达方向是否与扩增/非扩增患者的真实表达差异一致。同时单独评测 LLM 代理是否能将自然语言请求准确映射到 CASCADE 的真实 MCP 工具调用参数上。

## 2. 方法论

### 2.1 架构核心
- **CASCADE 框架**：Python 包，通过 LangGraph 编排的工作流（`CascadeWorkflow.run()`）和 MCP 服务器暴露基因扰动分析能力，沿用 RegNetAgents 的多代理编排模式，但分析方向相反——后者识别上游调控因子，CASCADE 预测下游扰动后果。
- **网络传播算法**：确定性广度优先算法，沿 ARACNe 网络有向边（regulator → target）传播有符号扰动信号：敲低时焦点基因初始效应为 -1.0，每跳效应乘以边权重和衰减因子 0.5，跨路径累加；边权重为 ARACNe 互信息量级，由激活/抑制模式注释决定符号（激活边保留符号，抑制边翻转符号）。
- **嵌入增强**：网络传播与 GREmLN 嵌入余弦相似度按 α=0.7 加权混合，嵌入层可增加网络不可达的候选基因，但不会翻转网络可达基因的方向。
- **默认参数**：传播深度 2 跳，默认 top-k=25（本实验用 top-k=50），13 种 TCGA 癌症类型的预计算 ARACNe 网络（来自 Bioconductor aracne.networks 包，2015 年 TCGA RNA-seq 数据构建）。
- **基因角色分类**：由网络出入度阈值决定（主调控因子、转录因子、次要调控因子、效应因子、孤立基因），用于路由分析路径。

### 2.2 方向一致性验证方法
- 取 top-50 预测靶标基因，记录每个基因的预测方向（敲低后下调/上调）。
- 将 GISTIC2.0 拷贝数扩增（离散值=2）视为焦点基因活性增加的剂量代理（即敲低的逆效应）。
- 对比扩增组与非扩增组（GISTIC=0）患者样本的平均 mRNA 表达 z-score：预测敲低后下调的基因在扩增样本中应更高表达（一致），预测上调的基因应更低表达（一致）。
- **统计检验**：单侧二项检验（零假设：一致率=50%）+ 独立置换控制（1000 次从 200 个背景基因池中抽取，排除焦点基因和预测靶标集合，保持真实方向比例随机分配方向标签）。
- 排除任一组少于 10 个样本的基因。

### 2.3 智能体工具调用接地评测
- 使用 CASCADE 真实 MCP 工具定义（verbatim），构造 35 个手工标注的自然语言查询，覆盖 7 个类别（各 5 条）：基线 TCGA 癌症类型、免疫细胞类型、基因别名、非正式癌症名、非规范扰动动词、隐式省略参数、多重实体干扰项。
- 两个本地模型通过 Ollama 测试：llama3.1:8b（CASCADE 文档默认）和 qwen2.5:72b（更大模型的次要对比）。
- 逐字段对比模型输出的工具调用参数与真实标准答案；基因别名另有服务端 `resolve alias()` 步骤后的二次评分。

## 3. 实验设计

### 3.1 数据集与场景

- **三个癌症类型**：BRCA（乳腺癌）、COAD（结肠癌）、STAD（胃癌）。
- **PAM50 亚型对照**：限制在亚型组成最均衡的 Luminal B 内重测。
- **15 个额外基因的泛化测试**：增殖机制基因（E2F3、CCND1、CCND3、AURKA、CCNE1、MDM2、FOXM1、TOP2A、RPS6KB1、CCND2）和谱系同一性/RTK 组（SOX9、FOXA1、GATA3、ESR1、ERBB2），共 27 个基因-癌症类型组合。
- **智能体工具调用基准**：35 条查询 × 2 个模型。

### 3.2 对比方法
- **与 MSigDB 精选基因集基线对比**（Fisher 精确检验）：MYC TARGETS V1（三种癌症）和 E2F TARGETS（仅 BRCA，对 E2F3），使用每个集合的全部可解析基因（188–197 个）。

## 6. 主要结论与发现

1. **MYC 预测方向一致性强**：BRCA 90.0%（p<10^-8）、COAD 72.0%（p=0.0013）、STAD 85.7%（p<0.0001），置换经验 p=0.0000（1000 次无一匹配）；面板大小从 25 到 100 之间一致率稳定在 88–92%。
2. **PAM50 对照通过**：Luminal B 亚型内 92.0% 一致率（强于全队列）。
3. **METABRIC 独立复制**：87.2%（p<10^-6），排除共享 TCGA 数据伪影。
4. **方向性判断是必要的**：强制统一"下调"预测导致一致率下降 14–29 个百分点；上调预测子集自身准确率 76.5–92.3%，排除了"上调只是噪声"的可能。
5. **但未超过先验知识**：与 MSigDB MYC TARGETS V1 基线差距仅 1–4 个百分点，双向不一致，Fisher 精确检验均不显著（p=0.34–0.86），BH 校正后 q=0.767–0.863；E2F3 名义上高于基线但无显著差异（p=0.384）。
6. **泛化是基因特异性的**：9/10 增殖机制基因至少在某癌症类型中验证（E2F3、CCND1、AURKA、CCNE1、FOXM1、TOP2A 等 89.6–100%；MDM2 和 CCND3 较弱 68–76%），而所有谱系同一性转录因子（SOX9、FOXA1、GATA3、ESR1）和 CCND2 都失败（0–38.8%，反一致）；ERBB2 在 BRCA/COAD 反一致（18.0%/14.3%）但在 STAD 强一致（93.6%）。
7. **跨癌症不一致**：CCND1 在 STAD 失效（57.1%）、MDM2 在 STAD 失效（42.0%），均在 BRCA 成功；CCND2 是唯一在所有测试癌症类型中都失败的增殖基因（38.0% 在 BRCA 反一致）。
8. **智能体工具调用**：llama3.1:8b 精确匹配 71.4%；qwen2.5:72b 达 85.7%。两种失败模式（网络参数模式遵循、基因别名）分别通过更大模型和服务端别名解析解决（服务端解析后升至 77.1% 和 94.3%）；第三种失败——模糊查询时自信错误地默认扰动类型——两个模型都有发生，且针对性修复无效，因为模型总是填值从不留空。

## 7. 优点

- **验证范式创新**：用真实患者基因型-表达数据直接检验方向性预测，替代仅检验成员资格的数据库富集验证，对 MCP 暴露工具更贴切。
- **代理选择的生物学合理性**：拷贝数扩增作为敲低逆代理有清晰的剂量逻辑，且通过 PAM50 亚型对照和 METABRIC 独立队列系统性排除混杂。
- **严格的统计框架**：置换检验排除基因集结构伪影，多重检验校正（27 组合 BH-FDR），Fisher 精确检验处理不同样本量，显著性好且稳健。
- **罕见的高透明度**：公开所有基因选择和入选/剔除标准、公开失败案例、披露 ESR1 是证伪性选择、意识到并坦诚讨论事后假说偏差风险。
- **消融设计精密**：嵌入消融（排除 GREmLN 混合伪影）、方向消融（排除"全下调"朴素基线）、面板规模扫描（排除阈值武断）。
- **生物学连贯性**：预测的拓扑一致性基因（NOP14、NOB1、RIOK1 等核糖体生物发生组件）正好是 MYC 最成熟的转录程序，提供独立的生物学可信度证据。

## 8. 不足与局限

- **基线对比无法证明超越先验知识**：CASCADE 与 MSigDB 精选基因集在 MYC/E2F3 上无显著差异（p=0.34–0.86），表明其优势可能不在"列出哪些基因"而是"预测方向本身"；但这只在 2 个精选集合上测试过。
- **泛化受限**：十五个基因、二十七组合规模有限；强扩增驱动基因稀有（CTNNB1、KLF5、MYB 等因扩增样本不足无法测试）；结论可外推性受限。
- **基因类分裂机制未解**：CCND1/MDM2 跨癌症不一致、CCND2 与其旁系同源基因（CCND1/CCND3）相反、ERBB2 方向完全反转（BRCA/COAD 反一致 vs. STAD 一致），论文只能给出事后假说（增殖机器 vs. 谱系同一性），承认非预设机制。
- **拷贝数代理的固有局限**：扩增≠敲低逆效应不是完美等式；某些基因（如 GATA3）以点突变而非扩增驱动，代理可能不适配；肿瘤纯度、基质污染、扩增子共选等因素未检验。
- **智能体基准有限**：35 条查询不构成精确的泛化准确率估计；仅测两个本地模型，未测专有前沿模型（可能模式遵循更好）；仅评价单次决策而非多轮行为/纠错能力；Ollama 无种子导致可复现性差。
- **扰动类型歧义失败未解决**：两个模型都自信地填写错误的枚举值，触发条件（字段留空）从未出现，服务端修复对惰性；更有效的修复（验证填充值是否有查询文本支持）未实现。
