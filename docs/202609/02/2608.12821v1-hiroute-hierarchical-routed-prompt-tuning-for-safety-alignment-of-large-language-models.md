## 摘要
大语言模型（LLM）仍然容易受到有害请求和越狱攻击的影响。基于提示微调的参数高效安全对齐方法通常依赖单一的全局提示或外部选择的提示模块。这种静态设计难以在针对特定风险生成建设性响应的同时，维持跨类别的安全边界，并避免对良性输入的过度拒绝。为解决这些局限性，我们提出了HiRoute，一种输入自适应的分层提示微调框架，将类别无关的安全控制与类别特定的响应引导分离。HiRoute首先在冻结的LLM提取的表示上训练一个轻量级分层路由器，以联合检测有害意图并预测多标签风险分数。然后，它冻结主干模型和路由器，并使用带有交替梯度更新的偏好优化来学习一个共享的粗粒度提示和一组细粒度的提示专家作为连续嵌入。在推理时，良性输入绕过安全分支，而风险输入则使用共享提示以及路由器加权的风险特定提示专家混合进行处理。在三个指令微调模型上的实验表明，HiRoute在多个安全基准上实现了高安全率，同时保持了安全响应的有用性，减少了过度拒绝，并在通用任务上保持了有竞争力的性能。

## Abstract
Large language models (LLMs) remain vulnerable to harmful requests and jailbreak attacks. Parameter-efficient safety alignment methods based on prompt tuning typically rely on a single global prompt or externally selected prompt modules. Such static designs struggle to maintain a cross-category safety boundary while generating constructive responses tailored to specific risks and avoiding over-refusal of benign inputs. To address these limitations, we propose HiRoute, an input-adaptive hierarchical prompt-tuning framework that separates category-agnostic safety control from category-specific response guidance. HiRoute first trains a lightweight hierarchical router on representations extracted from a frozen LLM to jointly detect harmful intent and predict multi-label risk scores. It then freezes both the backbone model and the router and uses preference optimization with alternating gradient updates to learn a shared coarse-grained prompt and a set of fine-grained prompt experts as continuous embeddings. At inference time, benign inputs bypass the safety branch, whereas risky inputs are processed using the shared prompt together with a router-weighted mixture of risk-specific prompt experts. Experiments across three instruction-tuned models show that HiRoute achieves high safety rates across multiple safety benchmarks while preserving safe-response helpfulness, reducing over-refusal, and maintaining competitive performance on general-purpose tasks.

## 二、论文提出的方法论

### 2.1 核心思想
- 将安全提示分为两个层级：
  - **共享粗粒度提示（Pc）**：提供跨类别、类别无关的稳定安全边界。
  - **细粒度提示专家（{Pk}）**：一组按风险类别区分的提示嵌入，通过路由器预测的风险分布加权组合，提供风险特定的解释、合规指导和安全替代方案。
- 通过**层次化路由器（hierarchical router）** 判断输入是否需要安全接管，并输出多标签风险分数，用于动态组合提示。

### 2.2 关键技术细节

**（1）提示构建与组合：**
- 路由器输出的细粒度风险概率 `pf(x)` 经归一化得到组合权重 `αk(x)`：
```
Pf(x) = Σk αk(x) · Pk，  αk(x) = pf,k(x) / Σj pf,j(x)
```
- 层次化安全提示拼接到输入嵌入之后：
```
P(x) = [Pf(x); Pc]， CP(x) = [Eθ(x); P(x)]
```
其中，粗提示 Pc 提供类别无关安全约束，Pf(x) 注入当前输入所需的类别特定引导。

**（2）层次化路由器（Rϕ）：**
- 以冻结 LLM 的最终层隐状态作为输入，经轻量 Transformer 编码器（8 注意力头）编码后进行掩码平均池化得到输入表示。
- **粗粒度分类头**输出 `[psafe, prisk]`，用交叉熵损失训练，指示是否激活安全分支。
- **细粒度分类头**对 K 个风险类别（网络犯罪、经济犯罪、隐私侵犯、暴力）各自独立输出 sigmoid 概率，用二元交叉熵损失训练，支持多标签风险预测。

**（3）两阶段解耦式训练：**
- **阶段 I（路由学习）**：冻结主干，先单独优化粗粒度分类（学习通用安全/风险决策边界），再联合优化粗、细粒度两个头。`Lrouter = Lc + Lf`。
- **阶段 II（风险自适应提示学习）**：冻结主干与路由器，仅优化提示参数。对偏好三元组 `(x, yw, yl)` 应用 DPO 损失，增加安全且有用响应（yw）相对于不安全或低质量响应（yl）的条件似然。训练中使用**交替梯度遮蔽（alternating gradient masking）**：
  - 更新 Pc 时遮蔽 Pf(x) 的梯度，更新细粒度专家时遮蔽 Pc 的梯度；
  - 前向过程始终使用最终组合上下文 `[x; Pf(x); Pc]`。
``` 
sg(z) = z，  ∇z sg(z) = 0
```

**（4）输入自适应推理：**
- 如果 `psafe(x) > τs`（默认 0.95），则判定为良性输入，绕过安全提示直接在冻结骨干上生成。
- 否则进入风险控制分支，用路由器估计的风险分数加权组合细粒度专家并与共享粗提示拼接，再送入冻结模型生成响应。

## 六、论文的主要结论与发现

1. **粗/细粒度提示存在互补性局限**：单一粗粒度安全提示的安全率高，但安全响应有用性低（倾向通用保守拒绝）；路由细粒度提示混合生成更有针对性的安全响应，但安全率显著较低（缺少类别无关兜底约束）。
2. **HiRoute 有效融合两者优势**：在 3 个骨干模型上，与其他提示微调安全对齐方法相比：
   - 平均安全率为最高（Mistral 93.2%、Vicuna 97.7%、Zephyr 94.8%）；
   - 平均安全响应有用性同时超过所有对齐基线；
   - 相对于 Base 模型在提升安全率的同时没有牺牲有用性。
3. **不过度拒绝**：XSTest over-refusal 率在安全对齐方法中最低（Mistral 2.5%、Vicuna 3.0%、Zephyr 7.0%），说明安全增益源自对风险的精准识别而非保守的全面拒绝。
4. **门控阈值**：安全控制与通用能力存在可控权衡——提高 τs 可明显改善安全率，对 GSM8K 精度的损耗很小（50.5% → 48.0%）。
5. **对越狱鲁棒**：在迁移式 GCG 攻击下，平均安全率由 34.6% 上升至 88.3%。
6. **可缩放**：在 Vicuna-13B-v1.5 上同样保持有效并维持通用能力。

## 七、优点

- **创新性强**：明确提出“安全控制”与“风险特定响应引导”解耦的设计原则，首个将粗粒度类别无关提示 + 路由器加权细粒度专家 + 安全门控三者整合进统一提示调优框架。
- **输入自适应**：突破了既有方法单一固定提示的限制，使提示构造基于输入风险的实时预测而动态变化，更贴合真实场景中多样化和复合型风险请求。
- **参数量高效**：主干模型与路由器完全冻结，仅优化共享提示和少量专家提示嵌入，训练成本低、部署便利，容易迁移到不同骨干模型。
- **实验设计严谨**：对安全（2 维：安全率与有用性）和通用能力同时评估，防止单维度优化倾向；设置多个对照消融研究验证各组件的有效性与必要性，并且安全评测集与训练监督来源隔离。
- **动机实证充分**：先用初步实验证明两种单一策略（单一粗提示 vs. 纯路由细提示）存在互补的局限性，再构建分层框架，叙述逻辑具有很强的说服力。

## 八、不足与局限

- **对路由器性能存在较强依赖**：路由器误判或未见过分布外（OOD）复合风险输入时，会产生次优专家权重，降低安全控制的稳定性与特异性。论文虽报告了路由器的 F1 与准确率，但消融中未充分讨论路由错误对端到端安全的下游影响。
- **评价局限**：
  - 主要实验停留在单轮文本交互，未覆盖多轮对话、多模态输入等更具挑战性的场景。
  - 安全率与有用性主要依赖 GPT-5.4 自动评价，人工验证样本量较少（20 条），存在评估偏差风险；
  - 细粒度风险类别仅覆盖 4 类，对于未标注类别或全新攻击模式仍需依赖粗粒度边界兜底。
- **安全与能力之间仍有潜在权衡**：虽然 HiRoute 明显优于基线，但在某些通用指标上（例如 Vicuna 上 GSM8K 较 Base 略降，Zephyr 上 GSM8K 仍低于 Base 未对齐模型），安全对齐依然伴随一定程度的能力折损，可能需要更精细的门控或分层机制来进一步缓解。
- **鲁棒性验证深度有限**：GCG 实验评估的是迁移攻击而非直接针对 HiRoute 路由器与提示参数的白盒自适应攻击，对于防御对抗性更强的攻击形态，论文对其鲁棒性的说明相对有限。
- **训练配置披露不完整**：未报告训练时间、提示参数量和显存占用等资源细节，不利于复现与资源预算的精确评估。

## 结语

HiRoute 以“层次化路由器（识别风险）→ 共享粗提示（安全边界）→ 路由细提示专家（构建建设性安全响应）”的分层架构，有效弥合了提示调优安全对齐中“单一提示过于保守”与“纯细粒度路由安全不足”的双重局限。总体而言，该方法兼顾安全、有用性、通用能力、参数量效率与低过度拒绝，是对基于提示的参数高效安全对齐路径的一次有力推进。但距离实际应用仍存在路由误判、多轮/多模态扩展与评估偏差等挑战，是未来工作中值得继续深耕的方向。
