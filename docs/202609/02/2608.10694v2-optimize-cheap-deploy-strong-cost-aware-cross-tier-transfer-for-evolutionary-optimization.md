## 摘要
LLM提示词及智能体程序的进化优化（如GEPA）主要由适应度评估主导：对每个候选者进行评分需要在验证集上运行作答LLM，因此评估模型的价格层级决定了总搜索成本。我们通过解耦LLM所扮演的三重角色来重构这一搜索过程：将高容量的作答角色置于最廉价的层级，将强模型保留给罕见的反思/变异算子，然后利用向上的跨层迁移，将廉价进化得到的提示词部署到更强的目标模型上。我们提供了一种成本受控的表征，说明何时廉价层搜索可替代目标层搜索，以及何时失效。在四个任务（HotpotQA、IFBench、LiveBench-Math、HoVer）和四个模型家族的十一个模型上，所得提示词在匹配或超过同层优化效果的同时，将超过96%的搜索token置于最廉价层级，搜索成本降低5.6至14倍；在推理层级每次适应度调用都会生成长思维链的情况下，成本降低高达25至54倍。

## Abstract
Evolutionary optimization of LLM prompts and agentic programs (e.g., GEPA) is dominated by fitness evaluation: scoring each candidate runs an answering LLM over a validation set, so the evaluator's price tier dictates total search cost. We restructure that search by decoupling the three roles an LLM plays, running the high-volume answering role on the cheapest tier, reserving a strong model for the rare reflection/variation operator, then exploiting upward cross-tier transfer to deploy the cheaply evolved prompt on a stronger target. We contribute a cost-controlled characterization of when cheap-tier search substitutes for target-tier search, and where it fails. Across four tasks (HotpotQA, IFBench, LiveBench-Math, HoVer) and eleven models in four model families, the resulting prompt matches or exceeds same-tier optimization while placing over 96% of search tokens on the cheapest tier, at 5.6-14x lower search cost, rising to 25-54x where reasoning tiers emit long chains of thought on every fitness call.

### 1. 核心问题与研究动机

进化计算在LLM提示词与智能体程序优化中（如GEPA、PromptBreeder等）面临一个根本性瓶颈：**适应度评估（fitness evaluation）占绝对主导地位**。每个候选提示词需要在验证集上运行作答LLM，因此评估模型的单token定价直接决定了整个搜索的总成本。

关键症结在于现有范式中**搜索与部署纠缠在同一模型上**：
- 为强目标模型优化提示词，整个搜索就必须在该昂贵目标上运行
- 为维持统计显著性，验证集不能太小
- 大量token用于作答（占96%以上），导致总成本被高容量评估所支配
- 预算受限时被迫压缩种群大小和世代数，牺牲最终质量

作者提出一个根本性疑问：**搜索是否必须运行在最终部署的模型上？** 论文给出的答案是否定的，并将这一朴素洞察发展为一种系统的**跨层成本迁移策略**。

### 2. 方法论：Cost-Aware Cross-Tier Optimization

#### 2.1 核心思想：解耦LLM的三种角色
论文将进化循环中LLM扮演的三个角色彻底分离：
- **作答角色（answering）**：由最廉价模型担任，高频执行（占96%以上token）
- **反思/变异角色（reflection/variation）**：由强模型担任，低频触发（不到5%的搜索调用）
- **部署角色（deployment）**：部署时自由选择任意更强的目标模型，零样本迁移

#### 2.2 三个关键组件
- **(A) 廉价适应度层**：候选提示词在验证集上运行最便宜的作答模型`M_task`。它并非需要标定的数学代理，而是搜索期间的实际执行环境。核心逻辑是：评估只需要*足够好地排序候选者*引导选择，不需要精确估计其部署质量。
- **(B) 强变异算子**：强反射器`M_refl`读取廉价模型的执行轨迹并撰写精准编辑。变异算子需要高精度、理解轨迹、重写提示词，这是强模型能够兑现价值的地方，且调用量稀有。实测每个被接受候选所需变异调用2.7-46次，反射仅占全部搜索调用的<5%（0.08%-4.95%），但承载约12%-46%的搜索支出，属于有限溢价。
- **(C) 向上跨层部署**：最终进化所得提示词零样本部署到更强的`M_dep`，无需映射、校准或重新优化。一次搜索可以分摊到任意多个部署层级。

#### 2.3 理论公式

**目标分解**：将搜索经验目标`J_task`与部署目标`J_dep`之差定义为跨层迁移残差：

```
J_dep(Π) = J_task(Π) + Δ(Π)，其中 Δ(Π) := J_dep(Π) − J_task(Π)
```

**目标后悔（target regret）**：

```
R_s→t = J_t(π*_t) − J_t(π*_s)
```

**两个核心假设**：
- **零样本迁移（弱主张）**：R ≈ 0，廉价搜索所得提示词在部署模型上近最优
- **零样本正向迁移（强主张）**：R < 0，不仅无损耗还有正面收益

**成本模型**（式4）：

```
C_opt ≈ (K·N_val + 2Ab)·c(M_task) + A·c(M_refl)
```

其中`K·N_val`（全验证集评估）主导成本，变异项只占少量调用。移动作答层级即可移动几乎全部账单。

#### 2.4 机制解释：为什么向上迁移能够成功？
- **角色不对称性**：变异算子必须读取轨迹并写出高精度编辑，这需要强模型的能力且只调用少量次数；而适应度评估只需对候选进行足够好的排序，这是便宜且嘈杂的评估器在绝大多数比较中可以胜任的。
- **结构性显式化假说**：强/前沿模型可自行跨越逻辑跳跃，因此原生在它上面进行的搜索可以沉淀出依赖评估模型推理的隐式编码提示词；而廉价作答模型面对歧义会失败，倒逼反射器写出显式、严谨、带防护栏的提示词——前沿模型恰好有能力吸收这种清晰度。
- **证据**：跨52对的配对比对显示廉价搜索生成的提示词更长（中位比值1.29×），指令密度更高（1.26×）、禁令密度更高（1.17×）、全大写强调密度高达2.80×。

### 6. 主要结论与发现

1. **主旨结论**：同一个提示词仅用最便宜的答案评估器从头搜索一遍，配合强反射算子，即可匹配甚至超过在每个层级上直接运行完整优化获得的提示词性能，同时搜索成本降低一个数量级以上。
2. **数量级成本缩减**：Mixed Claude 与 GPT 梯子上为5.6-14倍，Gemini上为25-54倍（两推理层级在每次适应度调用时均发射长链思维），自部署Qwen3-8B时可将API账单降至反射器本身开销（< $2/次运行）。
3. **48个部署中36个达到或超过同层基线，其余最多落后3.8分**，平均残差+2.8%（95%CI [+1.3, +4.4]），在低价阶梯和跨任务上有向上的不对称分布。
4. **跨层向上迁移是可靠的**：同一廉价提示在12个（任务×家族）配对中全部表现出增益趋势；它不会像横向迁移到同级可比模型（如Wang 2025b报告的"模型漂移"）那样退化。目标层的价格并不映射到语义质量，17/75对阶梯对中更贵的模型反而得分更低。
5. **反射器的强度是杠杆而非廉价性**：2×2消融显示，在同层（nano评估）上两个标准配置并不比弱反射路径差，但部署到Haiku上测试时性能则显著拉开15分差距。提升反射器价值（+15.1/9.0分），而恢复完整成本的评估器仅增加有限交换价值（+1.4分）。从方法上看，配方是"强反射、弱求值"。
6. **提升源于显式结构**：廉价最优提示较长、指令密集、禁令密集，使用更多大写强调。弱评估器迫使反射器将搜索假设显式化，而强模型则具有使用这种清晰度的能力。
7. **应用边界**：廉价搜索的答案是嵌套在目标层语义饱和点以内的（有些任务中未优化种子提示即可达到与完整优化相同效果），同时廉价评估器必须维持在最低可行性能力基线之上。

### 7. 优点

1. **清晰的角色解耦定式**：将昂贵进化总成本中的高频低智能答案解耦，采用分层的稀疏高智能变异，该设计逻辑清晰严谨，逻辑实践潜力巨大。
2. **系统性跨层迁移研究**：在3个商业级和1个自托管模型家族中选取4种任务类型（问答、指令跟随、数学推理、检索密集的文档验证），规模宏大且结论具有稳健性。
3. **朴素而有洞察力的假设检验**：大量零成本/种子/零种子基线和详细测量，定义了两个转移的概念（per-prompt和目标遗憾），对于模型的机制可迁移性并未混淆。
4. **方法论严谨**：
   - Break-even λ分析量化了依赖价格表的敏感性，宣称在价格完全平价情况下依旧可在15/24个单元中保持可行性；
   - 统一的token测量与每个单元的真实记录成本的表格输出，提升了结果的可复现性与可更新性；
   - 报告了完整页面计数和提示词缓存敏感度测算；
   - 盲区与错误风险均有呈现（如IFBench@3.5-flash与种子类似胜过该层的完整优化）；
   - 搜索曲线报告了与实际部署表不同视角的结果，避免对搜索负载进行指数式膨胀。
5. **开放性讨论**：包括主要风险界限（目标最优质量的系统提示，最低任务/评估能力边界）以及重新研究的可能性。

---

### 8. 不足与局限

1. **可部署性与公平性范围有限**：缺少对代表性真实世界输入和部署的覆盖，任务类型（4）并不足以支撑跨代策略的一般性结论。
2. **边界限制**：
   - 廉价评估器必须保持最低水平成功能力（得分约0则完全不适用，搜索停滞）
   - 目标层级若已位于提示不敏感的封顶状态，则优化对任何方法都不提供收益——如 LiveBench-Math 上种子提示已超过所有方法（由Finding 4揭示），这是进化提示优化本身的基本限制
3. **价格表依赖**：虽然进行了break-even分析，但提供商的层级结构依然是一种先决条件（因此并非最昂贵层级上的价格价差的普遍结论），任何改变各角色内部成本结构的方向都会影响其在未来协议中的适用性。
4. **明确性假设证据较弱**：明确性指标构成的对49对等对的分析依赖固定词库分析，虽然进行了多个定性阅读，但不能计算相互作用的因果检验；机制解释仍需设定专门的操控实验（如通过手动改变提示明确性再测量性能增益），作者承认还需要更充分的工作。
5. **记忆化/提示缓存等混杂项并非充分可控**：廉价和完整成本提示均从验证集携带记忆内容，而长度不对称通常构成提示成本。
6. **仅覆盖有限研究面**：没有覆盖廉价层与远迁移到不同架构的情况；尽管反射器模型并未提供对部署家族的暴露，初始分析使用的"混合Claude→mini"场景也未明确设计为跨架构障碍测试。
7. **跨模块结论

7. **跨模块结论泛化受限**：论文所提出的迁移机制（廉价评估+强反射+向上部署）虽在四个任务上表现一致，但其跨模块可推广性仍有限——未覆盖多模态提示、代码生成、工具调用编排等其他进化优化热点领域；且所有任务均为单轮/短程序结构，缺乏对长周期、状态化智能体进化的证据支持，因而尚不足以宣称该策略适用于任意进化计算场景。

---

### 9. 总结

本论文以"将搜索成本从部署成本中剥离"这一朴素命题为起点，构建了一套系统的**跨层成本迁移范式**：用最便宜的作答模型承担高频率的适应度评估（占96%以上token），用最强模型承担低频率高价值的反射变异（<5%调用），再让最终提示词零样本向上迁移至任意更强的目标模型。由于评估与部署的角色不对称性和提示词结构显式化机制，这一看似"偷工减料"的做法在48个部署单元中实现了36个达到或超过同层全成本优化的成绩，并在全部12个跨层配对中表现出正向迁移趋势，成本降低达5.6-54倍。

论文在方法论上最值得称道之处在于对成本、目标与迁移残差的形式化界定，以及2×2角色消融、弱反射器对照、跨优化器验证、break-even分析与种子基线的密集设计——这使得"反射器强度而非评估器成本"成为核心杠杆的结论具有相当的可信度。同时，作者对应用边界（廉价评估器最低能力基线、目标层提示饱和）与研究局限（明确性机制证据较弱、价格表依赖、架构外推不足）的坦诚讨论也保持了学术上的清醒。

对于从事LLM提示词/智能体程序自动优化的研究者与工程师而言，本文提供了一个立即可采用且成本收益显著的操作建议：**不要在目标模型上做全成本搜索，而是让廉价模型当"跑腿的"，让强模型当"出主意的"，最后把成果直接交给目标模型去部署。** 当然，该策略能否在更广泛的任务族与更长远的多轮智能体演化中持续成立，仍有待后续研究的检验与扩展。
